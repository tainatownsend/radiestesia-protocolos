# Protocolos Interativos

Aplicação web estática com dois protocolos:
- Vida Financeira
- Carreira / Profissional

## Recursos
- respostas acumulativas;
- múltiplos achados na mesma sessão;
- priorização;
- síntese final automática;
- intensidade antes/depois;
- campos de método e observações;
- histórico local via localStorage;
- compatível com GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `app.js` e `.nojekyll` para a raiz.
3. Vá em Settings > Pages.
4. Em Source, escolha `Deploy from a branch`.
5. Selecione `main` e `/ (root)`.
6. Abra a URL publicada no Safari do iPad.
7. No Safari: Compartilhar > Adicionar à Tela de Início.

Observação: o histórico fica apenas no navegador/dispositivo onde a aplicação é usada.
